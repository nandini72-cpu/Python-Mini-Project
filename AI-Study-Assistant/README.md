# 🤖 AI Study Assistant

## 📌 Project Overview

AI Study Assistant is a Python-based application that uses Google's Gemini AI to help students learn and prepare for interviews.

The application allows users to:
- Explain academic topics in simple language
- Generate multiple-choice quizzes
- Generate interview questions
- Ask general study-related questions

## 🎯 Objective

The main objective of this project is to create a simple AI-powered study assistant that helps students understand concepts and prepare for exams and interviews.

## ✨ Features

### 📚 Topic Explanation
The application explains a given topic with:
- Definition
- Simple explanation
- Real-world example
- Important points
- Short summary

### 📝 Quiz Generator
Generates 5 multiple-choice questions with:
- Four options
- Correct answer
- Explanation

### 💼 Interview Preparation
Generates interview questions with short answers.

### ❓ Ask Anything
Users can ask general questions and receive AI-generated answers.

## 🛠️ Technologies Used

- Python
- Google Gemini API
- Google GenAI Python SDK
- python-dotenv
